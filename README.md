# Nimol Thuon, PhD

I research low-resource document understanding and historical document analysis. I build datasets and methods for recognizing text, analyzing layouts, and answering questions about manuscripts and inscriptions, with a focus on Khmer and other underrepresented scripts.

[Academic homepage](https://back-kh.github.io/) | [Publications](https://back-kh.github.io/#publications)

## Featured Project

**[PalmLeaf-VQA](https://github.com/back-kh/PalmLeaf-VQA) (WACV 2027)** benchmarks visual question answering on historical palm-leaf manuscripts across eight collections. It focuses on layout and physical features such as visible text lines, binding holes, and manuscript condition.

[Project page](https://back-kh.github.io/palmleaf-vqa/) | [Paper](https://arxiv.org/abs/2609.31651) | [Public test set](https://huggingface.co/datasets/Backkh/PalmLeaf-VQA)

## Selected Research

- **[PALM-LAY](https://github.com/back-kh/PALM-LAY-Multi-Script-Cross-Regional-Dataset-for-Layout-Analysis):** A multi-script dataset for layout analysis of palm-leaf manuscripts.
- **[SADA](https://github.com/back-kh/SADA-Ancient-Palm-Leaf-Manuscripts-Recognitions):** Grammar-aware data augmentation for recognizing Khmer palm-leaf manuscript text.
- **[Angkorian-KSI](https://github.com/back-kh/Angkorian-KSI):** A multi-task benchmark for analyzing Khmer stone inscriptions.
